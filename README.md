# CONGELAZO

Congelados de terror en 3D, para el navegador. **No te muevas. No parpadees.**

Juega como participante (avanza mientras suena la melodía y quédate inmóvil cuando el vigilante se voltea) o como vigilante (voltea y señala a quien se mueva). Cuatro personajes, tres escenarios (Feria Muerta, Pasillo Anegado, Maizal sin Fin) y tres dificultades.

- Un solo `index.html` con Three.js; texturas, personajes y sonido generados por código.
- Funciona en celular, tablet y PC. En iPhone suena aunque el interruptor esté en silencio.

Jugar: https://gamexic.github.io/congelazo/
